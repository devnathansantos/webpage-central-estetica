# 🚗 Central Estética Automotiva

## 📌 Sobre o projeto

Este projeto foi criado com o objetivo de simular um site real de uma empresa de estética automotiva, focando em:

- Apresentação de serviços
- Organização de catálogo
- Experiência visual moderna
- Animações ao rolar a página

---

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Intersection Observer API

---

## 🎨 Funcionalidades

- ✅ Layout moderno e organizado
- ✅ Animações ao scroll (efeito reveal)
- ✅ Seção de produtos com grid
- ✅ Catálogo detalhado de serviços
- ✅ Feedbacks de clientes
- ✅ Botão flutuante de contato (WhatsApp)

—

## 🚀 Como executar

1. Baixe ou clone este repositório  
2. Abra o arquivo index.html no navegador
